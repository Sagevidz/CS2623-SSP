- **Apollo Server PHP Version Compatibility (`??` vs `isset()`):** The initial `include_header.php` used the PHP 7+ null coalescing operator (`$_SERVER["SERVER_NAME"] ?? "Server-Side Programming"`), which caused a syntax error (`unexpected '?'`) on the OCCC Apollo server. Modified to use `isset($_SERVER["SERVER_NAME"]) ? $_SERVER["SERVER_NAME"] : "Server-Side Programming"` so it works on both XAMPP and Apollo.
